# Gaurav Raju Nawale | Portfolio

A premium, minimalist portfolio built with **Next.js**, **Tailwind CSS**, and **Framer Motion**. Designed for clarity, professional confidence, and a "builder" mindset.

## 🚀 Design System: Aura Portfolio
The portfolio follows the **Aura Portfolio** design system:
- **Theme**: Light-themed with expansive whitespace.
- **Color Palette**: 
  - Primary: Soft Indigo (#4F46E5)
  - Secondary: Light Purple (#A855F7)
  - Background: Off-white/Soft Blue (#F8F9FF)
- **Typography**: **Plus Jakarta Sans** (Modern geometric sans-serif).
- **Aesthetics**: Subtle glassmorphism, soft ambient shadows, and elegant vertical pacing.

## 🛠️ Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion (Minimal & Smooth)
- **Icons**: Lucide React

## 📂 Project Structure
- `/src/components`: Reusable UI components (Hero, About, Projects, Skills, etc.)
- `/src/app`: App Router pages and global configurations.
- `/public`: Static assets and metadata.

## 🏃 Getting Started
First, install dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🚢 Deployment
Ready for one-click deployment on **Vercel**.

```bash
# To build for production
npm run build
```
